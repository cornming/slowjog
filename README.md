# SlowJog

陪你養成「早晨 30 分鐘運動 + 超慢跑」習慣的 Android App。第一版先做節拍器，之後陸續加入運動計時、每日提醒、桌面小工具與小人物動畫。

## 目前功能（第一版）

- **首頁直接設定今日目標**：首頁的「今日目標」可選「時間」（整段運動，0 到 90 分鐘，每 5 分鐘一格）或「距離」（超慢跑，0 到 10 公里，每 0.25 公里一格），下次按「開始運動」就採用。運動中畫面顯示還剩多久或還差多遠。
  - **距離是估算，不是量出來的**：App 沒有使用定位或計步器，距離＝超慢跑時間 × BPM（一拍算一步）× 步幅。步幅預設 50 公分只是起始值，請在「設定」依自己的情況校正（設定頁有校正方法）；BPM 中途調整會分段計算。室內跑步機也能用。
- **達成目標**：響起完成音效（6 款可選：煙火歡呼、勝利號角、清脆鐘聲、8-bit 過關、音樂盒、掌聲歡呼，或每次隨機且不連續重複；全部由程式合成、不是真人錄音，音量跟著手機媒體音量）、震動三下；**啟用課表時，要等課表每個階段都做完才算結束**（目標時間或距離先到也不會提早停掉節拍器與音樂）；預設還會自動結束超慢跑、停掉節拍器、用手機的媒體鍵暫停正在播放的音樂（Spotify 或其他音樂 App 都適用，不需要 Spotify 授權），再詢問是否儲存並結束。手動儲存結束時也會響完成音效。目標在運動期間由 App 內計時，若 App 被系統結束就不會觸發。
- **運動音樂（Spotify）**：在「設定」貼上 Spotify 歌單連結，一行一個（自己選的，或請 Claude 在對話裡建立的 AI 歌單都可以）。貼多個時每次運動隨機挑一個，不會連續兩次一樣；App 只能開啟你給的歌單，不會自己建立新歌單，所以要每次不同就得多給幾個。按「開始運動」時會詢問是否開啟歌單，也可以改成自動開啟或不使用音樂。App 會立刻開啟 Spotify 的歌單頁，由你按播放後再切回 SlowJog（不需要 Client ID、沒有等待時間；先前用 Spotify App Remote 直接播放的做法在實機上連線沒有回應，已移除）。
- **每日運動提醒**：預設每天 06:30（設定可改時間或關閉）發通知，附「開始運動」按鈕，按下會打開 App 並走和首頁「開始運動」一樣的流程（含詢問音樂）。今天已經運動就不提醒；連續漏掉兩天以上，當天會在原本時間後 3 小時補提醒一次（那時還沒運動才會響）。提醒用系統的省電鬧鐘，可能晚幾分鐘才響；開機、更新 App 後會自動重排。第一次開啟 App 會詢問一次通知權限。
- **桌面小工具**：在手機桌面加入「SlowJog」小工具（長按桌面 > 小工具），顯示累計超慢跑時間、連續天數與今天是否完成，點一下開啟 App。儲存運動後立即更新，平常由系統約每 30 分鐘更新一次（所以過了午夜最多晚半小時才換成「今天還沒運動」）。
- **習慣分數與每週目標**：「設定」可選每週目標天數（預設 5 天）。首頁顯示「本週 x / y 天」與習慣分數（0 到 100%），小工具也顯示分數。分數用最近 7 天運動天數 ÷ 每週目標當每天的完成度，逐日平滑累積：達到每週目標的休息日不扣分，偶爾漏一天只會小幅下降、不會歸零，但需要幾週才會爬高（連續做滿 30 天大約 76%）。目標天數要自己隨計畫調整，不會自動逐週增加。
- **匯出 CSV**：「設定」按「匯出運動紀錄」，選存放位置，欄位為 id、date、startedAt、durationSec、jogSec、bpm。
- **階段式課表與提示**：預設暖身 5、超慢跑 15、肌力 6、伸展 4 分鐘（共 30 分鐘，「設定」可調每段分鐘數，0 代表略過，也可整個關閉）。運動中畫面顯示目前階段與剩餘時間、下一階段；階段切換時用不同次數的嗶聲加對應次數的震動提示（暖身 1 聲、超慢跑 2 聲、肌力 3 聲、伸展 4 聲），提示可開關。課表依整段運動已過的時間走，暫停時不走。**自動接續**（設定可關）：每個階段結束前最後 5 秒倒數（畫面大數字、語音念「五、四、三、二、一」、每秒短嗶一聲），暖身結束自動開始超慢跑（節拍器響起）、超慢跑結束自動停止並進入肌力訓練，肌力結束再倒數進入伸展。倒數佔用前一階段的最後 5 秒，所以整段仍是 30 分鐘。運動期間會先開著前景服務待命（通知顯示「運動進行中」），自動開始節拍才不會被 Android 擋下；若系統還是不讓啟動，會維持沒在跑、請自己按「開始超慢跑」。
- **暖身、肌力與伸展動作示範**：暖身階段小人物依序示範抬膝踏步、手臂繞圈、轉體、屈膝半蹲；肌力訓練階段依序示範深蹲、原地弓箭步、提踵、抬膝碰肘、側抬腿（都是不需器材的站姿動作）；伸展階段（運動後的收操）依序示範小腿、大腿前側、前彎、上舉側彎、肩膀橫向伸展。每個動作至少 30 秒，階段太短就少做幾個；分左右的動作一個循環換一邊。畫面顯示動作名稱與要領，換動作時冒氣泡，語音開著會念出來。按了「開始超慢跑」後小人物改回跑步。動作是預先算好的 3D 影格（`mascot/moves.js`），不是真人示範，要領請當提示、不適就停。
- **語音播報**：階段切換與每 5 分鐘的經過時間，預設用手機內建的中文（台灣）語音念出，可開關；手機沒有中文語音時不會出聲。
- **做動作時的口令**（設定可單獨關）：停留型動作（伸展）每一側剩 10 秒提醒、最後 5 秒讀秒，左右分邊的動作換邊時喊「換邊」；反覆型動作（深蹲、抬膝等）剩 30 秒、10 秒提醒、最後 5 秒讀秒。階段結束前已經有倒數時不重複喊。
- **超慢跑鼓勵語音**（設定可單獨關）：每 1 到 2 分鐘說一句鼓勵（24 句），氣泡與語音同一句，點小人物也會說。
- **預錄語音（自然語音）**：App 支援 `assets/voice/<id>.wav` 的預錄語音檔，有檔案的句子優先播檔案，沒有的才用手機語音。語音稿 `tools/voice/script.csv`（63 句，網頁版共用），產生語音檔的腳本 `tools/voice/generate.py`（用 Google AI Studio 的 Gemini 語音合成，需要自己的 API 金鑰；沒有實際連線測試過），見 `tools/voice/README.md`。
- **節拍音色**：節拍器（答）、拍手、彈指三種，「設定」點選即試聽，下次開始節拍生效。音色是程式合成的，實際好不好聽要靠你的耳朵。
- **小人物陪跑與風景**：運動中畫面有陪跑小人物，可在「設定 > 外觀」選小藍（3D Q 版）、小橘（卡通描邊）、小點（像素風）、阿柴（穿運動服的擬人狗狗：T 恤、短褲、頭帶、白色肉球手）；四種共用同一套骨架與動作。超慢跑時小人物固定側面、腳步對齊節拍，背後的風景分層往後捲（遠景慢、近景快），速度跟著估算距離走，暫停就停；風景有河濱公園、城市清晨、森林步道、海邊，或每天輪換，也可以關掉捲動。不時冒出鼓勵氣泡，點一下小人物也會冒。
- **介面風格**：「設定 > 外觀」可選晨光（暖橘日出）、夜跑錶（深色大數字）、森林清晨（淡綠清爽），首頁、運動中、設定與紀錄都跟著換色。首頁有今天課表主卡、課表比例條、本週七天、累計超慢跑與估算總距離、習慣分數、目標與節拍器。
- **運動計時與紀錄**：按「開始運動」進入運動中畫面，整段運動與超慢跑階段分別計時；按「開始超慢跑」才啟動節拍器，結束超慢跑節拍器就停。可暫停、繼續，結束時選擇儲存或放棄。紀錄存在本機，「紀錄」分頁可查看每次的日期、整段與超慢跑時長、BPM，以及累計時間與連續天數。
- **節拍器**：BPM 可調（40 到 240，預設 180，對應超慢跑建議的每分鐘 180 步）。
- **點拍子定速**：跟著腳步連續點幾下，自動換算成 BPM。
- **節拍視覺閃動**：每一拍畫面亮一下，環境吵或音量小時也能對拍。
- **背景持續運作**：以前景服務執行，鎖定螢幕或切到其他 App 後仍會繼續，通知上有「停止」按鈕。
- **可與音樂同時播放**：節拍器不搶音訊焦點，可以邊聽 Spotify 邊用。
- **運動中螢幕恆亮**，停止後恢復系統設定。
- **檢查更新**：開啟 App 時自動檢查 GitHub 上的最新版，有新版就在首頁提示；按「下載並更新」會在 App 內下載 APK 並開啟系統安裝畫面。首頁也有「檢查更新」按鈕可手動檢查。第一次更新時，系統會要求允許 SlowJog 安裝應用程式。
- 沒有廣告、不追蹤。Android App 的網路權限只用來檢查與下載更新，只連到 GitHub，不送出任何使用者資料。（網頁版另有匿名的完成統計，見下方「網頁版」。）

## 下載與安裝

到 [Releases](../../releases) 下載最新的 `slowjog-v*.apk` 安裝。每次推送到 `main` 都會自動建置並發佈新版本，Release 頁面附有這個版本的更新日誌。

新版也可以在 App 內更新（見上方「檢查更新」）。安裝新版時可以直接覆蓋舊版，不需要先移除：所有版本都使用 repo 內固定的 debug keystore（`keystore/debug.keystore`）簽章，簽章一致才能覆蓋安裝。

## 版本與更新日誌

- 版本號自動遞增：`versionCode` 與 `versionName`（`0.1.<建置編號>`）由 CI 在建置時帶入，不需要手動修改。
- 更新日誌由兩次發佈之間的 commit 標題自動產生，因此 commit 標題請寫成人看得懂的一句話。
- App 首頁底部會顯示目前版本，方便確認有沒有更新成功。

## 本機建置

需要 JDK 17 與 Android SDK。

```bash
./gradlew test assembleDebug
```

APK 會產生在 `app/build/outputs/apk/debug/`。

## 網頁版（web/）

除了 Android App，也有一個可以在手機或電腦瀏覽器直接用的網頁版，放在 [`web/`](web/)：用 Rust + [Leptos](https://leptos.dev)（CSR）編譯成 WebAssembly、以 [Trunk](https://trunkrs.dev) 打包，做法與 [night-yoga](https://github.com/cornming/night-yoga) 相同。推到 `main` 會由 `.github/workflows/deploy-web.yml` 自動部署到 GitHub Pages（`https://<帳號>.github.io/slowjog/`；第一次要到 repo 的 Settings > Pages 把 Source 選成「GitHub Actions」）。網頁版不影響 Android 的建置（`build.yml` 與 Gradle 都沒動）。

**有做的功能**（邏輯從 Kotlin 版逐一移植，都有單元測試）：

- **階段式課表**：暖身 5、超慢跑 15、肌力 6、伸展 4 分鐘（共 30 分鐘），每段可調、0 分鐘略過、也可關掉。運動中顯示階段、剩餘時間、下一階段。
- **自動接續**：每個階段最後 5 秒倒數（大數字、讀秒、短嗶），暖身結束自動開始節拍、超慢跑結束自動停止並進入肌力。階段切換用不同次數的嗶聲加震動（手機瀏覽器才有震動）。
- **動作輪替與口令**：暖身、肌力、伸展依序念動作名稱與要領；停留型動作（伸展）剩 10 秒提醒、最後 5 秒讀秒、左右換邊喊「換邊」，反覆型（深蹲等）剩 30、10 秒提醒與讀秒。
- **超慢跑節拍器**：40 到 240 BPM（預設 180），用 Web Audio 預先排程，拍子由音訊時鐘決定、不會因計時器飄移（在瀏覽器實測 180 BPM 時每拍間隔固定 0.3333 秒）；三種音色（答、拍手、彈指，即時合成）；點拍子定速；每拍畫面脈動。
- **鼓勵語音**：超慢跑時每 1 到 2 分鐘一句（24 句），氣泡與語音同一句，點跑步圓圈也會說；另有每 5 分鐘報時、課表完成語音、完成音效（合成音）。
- **估算距離**：和 App 一樣是「超慢跑時間 × BPM × 步幅」的估算；沒有課表時可設時間或距離目標。
- **練習紀錄**：連續天數、本週天數、習慣分數（同 App 的指數平滑算法）、累計時間、本週打卡、最近 30 筆、匯出 CSV（欄位與 App 相同）。紀錄存在瀏覽器的 localStorage，換裝置或清除網站資料就會消失。
- 運動中螢幕恆亮（Screen Wake Lock，瀏覽器支援才有）、PWA（可加到主畫面、離線可用）、介面全部是台灣正體中文。

**語音**：沿用同一份語音稿 `tools/voice/script.csv`（63 句）與 Android 版的 `app/src/main/assets/voice/<id>.wav`，轉成 mp3 放在 `web/public/voice/<id>.mp3`（單聲道 64 kbps，共約 1.8 MB；用 `python3 tools/voice/to_web.py` 轉檔，需要 ffmpeg）。網頁版先找 `voice/<id>.mp3`，有就播，**檔案不存在或播不出來才退回瀏覽器內建語音**（台灣華語）；同一時間只念一句，其他排隊，讀秒會打斷前一句。語氣分類看 id 前綴：`count_`、`coach_`、`cheer_`、`move_`、`stage_`、`elapsed_`、`plan_done`。`cargo test` 會檢查語音稿與 `script.csv` 一致、63 句都有 mp3。重新轉檔後請把 `web/public/sw.js` 的 `CACHE` 版本號加一。

**匿名完成統計**（只有網頁版有，Android App 不會送出任何資料）：達成當次目標（課表走完，或時間／距離目標到了）並按「儲存並結束」時，網頁會匿名送出一筆紀錄：**完成當下的小時（手機的當地時間 0 到 23）、這個瀏覽器第幾次完成的分級（1、2、3、4+）**，伺服器端另外記下時間。沒有帳號、沒有裝置編號、不存 IP，也不使用 cookie。大家的統計公開在 <https://cornming.github.io/stats/>。中途結束、選「放棄這次紀錄」都不算完成。SlowJog 沒有固定課程，所以只統計完成次數、時段與回訪，沒有排行榜。「第幾次完成」的次數只存在使用者自己手機的瀏覽器裡（`slowjog:completions`），送出去的只有分級；換手機、清除瀏覽資料會被當成新的人，所以回訪率通常會偏低。收集端是一份 Google 試算表加 Apps Script，程式碼與部署步驟在 [cornming.github.io 的 `apps-script/`](https://github.com/cornming/cornming.github.io/tree/main/apps-script)，網址寫在 `web/src/web.rs` 的 `STATS_URL`。收集網址是公開的、沒有登入驗證，數字只是約略值。

**陪跑小人物與風景**（網頁版）：和 Android 版同一批素材。超慢跑時小人物依你的節拍踏步，一個步伐循環 12 格對應 2 拍，第 0 格與第 6 格（腳落地）對齊拍子，節拍快慢它就跟著快慢；背後的風景（河濱公園、城市清晨、森林步道、海邊，或每天輪換）分好幾層依估算距離捲動，遠的慢、近的快，暫停就停；暖身、肌力與伸展時示範 14 個動作（相鄰兩格疊合淡入，左右分邊的動作每個循環鏡像換邊）；點小人物會冒出鼓勵氣泡並跳一下，完成時撒彩帶。四種外型（小藍、小橘、小點、阿柴）與風景在「設定」選，系統開了「減少動態效果」時風景不捲動、不撒彩帶。影格表在 `web/public/mascot/`，是從 `app/src/main/res/drawable-nodpi/` 複製來的（去掉 `mascot_` 前綴），單元測試會檢查兩邊逐位元組相同。動畫用 requestAnimationFrame 直接改 DOM，規則在 `web/src/mascot.rs`、`web/src/scenery.rs`、`web/src/stage.rs`，有單元測試。

**背景音樂**（網頁版）：三種風格（輕快鼓點、晨光和弦、電子脈衝），全部用 Web Audio 即時合成，不需要音檔、離線可用、沒有版權問題；設定可選風格與音量，預設是輕快鼓點 70%。超慢跑時音樂掛在節拍器的排程上：每一拍的踢鼓、拍手、貝斯、琶音、和弦長音都和節拍器的「答」鎖在同一條拍子線上，節拍快慢音樂就跟著快慢（用探針量過：每個音都和「答」差不到 2 毫秒）；暖身、肌力、伸展沒有節拍，只播柔和的和弦長音；暫停就安靜；說話或倒數時音樂自動壓低。音樂經過限幅器再調音量，三種風格、任何音量疊上節拍器都不會爆音。音樂是合成的，不是真人演奏的歌，音色單薄是預期的；想聽自己的歌請在設定「背景音樂」選「不播放」，另開播放器（但跳去別的分頁會讓網頁版被降速，建議用耳機並讓畫面保持在 SlowJog）。純邏輯在 `web/src/music.rs`，有單元測試。

**讓人願意回來的小功能**（網頁版）：隔了 3 天以上沒運動，首頁會說「歡迎回來。今天先做完一次就好。」；剛好連續 3、7、14、30 天的那一天，今天做完後會說一句鼓勵；今天做完後首頁會出現「明天也來一次？」，可以選時間下載每天重複的行事曆提醒（.ics），或用 Google 日曆加入。提醒由手機的行事曆負責，網站不會記錄你選的時間。（網頁沒辦法在背景推播通知，要準時的提醒又想鎖屏跑步，請用 Android App。）純邏輯在 `web/src/comeback.rs`，有單元測試。

**省略或不同的地方**（網頁做不到或不適合）：

- 沒有背景運作：瀏覽器分頁被背景化或鎖屏後，計時與語音可能被節流或暫停（運動中會要求螢幕恆亮來減輕，節拍在背景時改為預先排程 5 秒），這是網頁與前景服務最大的差別；要鎖屏跑步請用 Android App。
- 沒有每日提醒通知、桌面小工具、App 內更新（網頁沒有對應的能力；提醒改用行事曆檔，見上方）。
- 沒有 Spotify：網頁沒辦法控制 Spotify，而且跳去別的分頁會讓網頁版被瀏覽器降速、節拍變不準，所以改成內建的合成背景音樂（見下方）。
- 沒有三種介面風格（晨光、夜跑錶、森林清晨）。
- 完成音效只有一款合成音（App 有六款）。
- 沒有感測器或定位：距離只能估算（和 App 一樣），不讀計步器。
- 運動進行到一半重新整理頁面，這次運動不會保留。

**本機開發**：

```bash
rustup target add wasm32-unknown-unknown
cargo install --locked trunk      # 或到 trunk-rs/trunk 的 Releases 下載執行檔
cd web
cargo test                        # 邏輯單元測試（課表、動作口令、引擎、統計、語音稿）
trunk serve --open                # http://127.0.0.1:8080
```
