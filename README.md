# SlowJog

陪你養成「早晨 30 分鐘運動 + 超慢跑」習慣的 Android App。第一版先做節拍器，之後陸續加入運動計時、每日提醒、桌面小工具與小人物動畫。

## 目前功能（第一版）

- **首頁直接設定今日目標**：首頁的「今日目標」可選「時間」（整段運動，0 到 90 分鐘，每 5 分鐘一格）或「距離」（超慢跑，0 到 10 公里，每 0.25 公里一格），下次按「開始運動」就採用。運動中畫面顯示還剩多久或還差多遠。
  - **距離是估算，不是量出來的**：App 沒有使用定位或計步器，距離＝超慢跑時間 × BPM（一拍算一步）× 步幅。步幅預設 50 公分只是起始值，請在「設定」依自己的情況校正（設定頁有校正方法）；BPM 中途調整會分段計算。室內跑步機也能用。
- **達成目標**：響起完成音效（約 4.6 秒的歡呼加三發煙火，全部由程式合成、不是真人錄音，音量跟著手機媒體音量）、震動三下；預設還會自動結束超慢跑、停掉節拍器、用手機的媒體鍵暫停正在播放的音樂（Spotify 或其他音樂 App 都適用，不需要 Spotify 授權），再詢問是否儲存並結束。手動儲存結束時也會響完成音效。目標在運動期間由 App 內計時，若 App 被系統結束就不會觸發。
- **運動音樂（Spotify）**：在「設定」貼上 Spotify 歌單連結（自己選的，或請 Claude 在對話裡建立的 AI 歌單都可以）。按「開始運動」時會詢問是否開啟這份歌單，也可以改成自動開啟或不使用音樂。App 會立刻開啟 Spotify 的歌單頁，由你按播放後再切回 SlowJog（不需要 Client ID、沒有等待時間；先前用 Spotify App Remote 直接播放的做法在實機上連線沒有回應，已移除）。
- **每日運動提醒**：預設每天 06:30（設定可改時間或關閉）發通知，附「開始運動」按鈕，按下會打開 App 並走和首頁「開始運動」一樣的流程（含詢問音樂）。今天已經運動就不提醒；連續漏掉兩天以上，當天會在原本時間後 3 小時補提醒一次（那時還沒運動才會響）。提醒用系統的省電鬧鐘，可能晚幾分鐘才響；開機、更新 App 後會自動重排。第一次開啟 App 會詢問一次通知權限。
- **桌面小工具**：在手機桌面加入「SlowJog」小工具（長按桌面 > 小工具），顯示累計超慢跑時間、連續天數與今天是否完成，點一下開啟 App。儲存運動後立即更新，平常由系統約每 30 分鐘更新一次（所以過了午夜最多晚半小時才換成「今天還沒運動」）。
- **習慣分數與每週目標**：「設定」可選每週目標天數（預設 5 天）。首頁顯示「本週 x / y 天」與習慣分數（0 到 100%），小工具也顯示分數。分數用最近 7 天運動天數 ÷ 每週目標當每天的完成度，逐日平滑累積：達到每週目標的休息日不扣分，偶爾漏一天只會小幅下降、不會歸零，但需要幾週才會爬高（連續做滿 30 天大約 76%）。目標天數要自己隨計畫調整，不會自動逐週增加。
- **匯出 CSV**：「設定」按「匯出運動紀錄」，選存放位置，欄位為 id、date、startedAt、durationSec、jogSec、bpm。
- **階段式課表與提示**：預設暖身 5、超慢跑 15、肌力 6、收操 4 分鐘（共 30 分鐘，「設定」可調每段分鐘數，0 代表略過，也可整個關閉）。運動中畫面顯示目前階段與剩餘時間、下一階段；階段切換時用不同次數的嗶聲加對應次數的震動提示（暖身 1 聲、超慢跑 2 聲、肌力 3 聲、收操 4 聲），提示可開關。課表依整段運動已過的時間走，暫停時不走。提示只是通知：節拍器仍要自己按「開始超慢跑」（背景自動啟動前景服務會被 Android 擋下）。
- **語音播報**：階段切換與每 5 分鐘的經過時間，用手機內建的中文（台灣）語音念出，可開關；手機沒有中文語音時不會出聲。
- **節拍音色**：節拍器（答）、拍手、彈指三種，「設定」點選即試聽，下次開始節拍生效。音色是程式合成的，實際好不好聽要靠你的耳朵。
- **小人物陪跑**：運動中畫面有 Q 版小人物，超慢跑時腳步對齊節拍；每 5 分鐘（超慢跑時間）轉換視角（正面、45 度側面、90 度側面、另一側 45 度，循環），不時冒出鼓勵氣泡。點一下小人物可以立刻換視角並冒出一則氣泡。
- **運動計時與紀錄**：按「開始運動」進入運動中畫面，整段運動與超慢跑階段分別計時；按「開始超慢跑」才啟動節拍器，結束超慢跑節拍器就停。可暫停、繼續，結束時選擇儲存或放棄。紀錄存在本機，「紀錄」分頁可查看每次的日期、整段與超慢跑時長、BPM，以及累計時間與連續天數。
- **節拍器**：BPM 可調（40 到 240，預設 180，對應超慢跑建議的每分鐘 180 步）。
- **點拍子定速**：跟著腳步連續點幾下，自動換算成 BPM。
- **節拍視覺閃動**：每一拍畫面亮一下，環境吵或音量小時也能對拍。
- **背景持續運作**：以前景服務執行，鎖定螢幕或切到其他 App 後仍會繼續，通知上有「停止」按鈕。
- **可與音樂同時播放**：節拍器不搶音訊焦點，可以邊聽 Spotify 邊用。
- **運動中螢幕恆亮**，停止後恢復系統設定。
- **檢查更新**：開啟 App 時自動檢查 GitHub 上的最新版，有新版就在首頁提示；按「下載並更新」會在 App 內下載 APK 並開啟系統安裝畫面。首頁也有「檢查更新」按鈕可手動檢查。第一次更新時，系統會要求允許 SlowJog 安裝應用程式。
- 沒有廣告、不追蹤。網路權限只用來檢查與下載更新，只連到 GitHub，不送出任何使用者資料。

## 下載與安裝

到 [Releases](../../releases) 下載最新的 `slowjog-v*.apk` 安裝。每次推送到 `main` 都會自動建置並發佈新版本，Release 頁面附有這個版本的更新日誌。

新版也可以在 App 內更新（見上方「檢查更新」）。安裝新版時可以直接覆蓋舊版，不需要先移除：所有版本都使用 repo 內固定的 debug keystore（`keystore/debug.keystore`）簽章，簽章一致才能覆蓋安裝。

## 版本與更新日誌

- 版本號自動遞增：`versionCode` 與 `versionName`（`0.1.<建置編號>`）由 CI 在建置時帶入，不需要手動修改。
- 更新日誌由兩次發佈之間的 commit 標題自動產生，因此 commit 標題請寫成人看得懂的一句話。
- App 首頁底部會顯示目前版本，方便確認有沒有更新成功。

## 本機建置

需要 JDK 17 與 Android SDK。

```bash
./gradlew test assembleDebug
```

APK 會產生在 `app/build/outputs/apk/debug/`。

## 專案結構

`mascot/` 放小人物的影格表與轉檔工具，詳見 [mascot/README.md](mascot/README.md)。

```

│   ├── WorkoutTimer.kt         # 整段與超慢跑計時（純 Kotlin，有單元測試）
│   ├── Target.kt               # 目標（時間或估算距離）與是否達成（有單元測試）
│   ├── TargetTime.kt           # 時間目標判斷（有單元測試）
│   ├── Distance.kt             # 距離估算：BPM × 時間 × 步幅（有單元測試）
│   └── WorkoutController.kt    # 一次運動的入口：開始、暫停、結束、達成目標、寫入紀錄
├── data/

│   ├── AppDatabase.kt          # 資料庫與 RecordRepository

│   └── CsvExport.kt            # 匯出 CSV（有單元測試）
├── settings/
│   └── AppSettings.kt          # 設定（目標、步幅、歌單、音樂模式），存在本機
├── sound/

│   └── BootReceiver.kt         # 開機／更新後重排

    ├── SettingsScreen.kt       # 設定分頁
```
